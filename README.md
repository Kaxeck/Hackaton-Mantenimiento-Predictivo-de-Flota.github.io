# 🚛 Proyecto Hackathon DEVF  
## EJE 3 · Mantenimiento Predictivo de Flota  
**Prevención y Disponibilidad**

## 📝 Descripción del Proyecto

Este proyecto fue desarrollado como parte del HACKATÓN BÉCALOS TRAXIÓN TECH 
CHALLENGE 2025, con el objetivo de proponer una solución digital al problema de mantenimiento reactivo en flotas vehiculares.

Se diseñó un **Prototipo Web (HTML y CSS)** que representa la interfaz de un **agente conversacional de mantenimiento predictivo**, el cual simula el análisis de variables operativas de una unidad para evaluar el riesgo mecánico y recomendar acciones preventivas.

El prototipo es una **interfaz estática**, enfocada en la experiencia de usuario y en la visualización clara de información clave, permitiendo entender cómo interactuaría un operador o administrador de flota con el agente antes de implementar una solución con lógica e inteligencia artificial real.

---

## 🎯 Objetivo del Proyecto

Diseñar un **agente conversacional** que permita pasar de un mantenimiento reactivo a uno **preventivo basado en riesgo**, utilizando señales tempranas y reglas simples para la toma de decisiones.

El prototipo web busca representar visualmente cómo el agente:

- Analiza variables básicas de la unidad  
- Evalúa el riesgo mecánico  
- Clasifica la prioridad de mantenimiento  
- Recomienda acciones preventivas claras  

---

## 🧩 Funcionalidades del Prototipo Web

- **Formulario de captura de datos de la unidad**
  - Kilometraje  
  - Tipo de unidad  
  - Condiciones de operación  
  - Alertas o códigos de falla simulados  

- **Semáforo de riesgo mecánico**
  - 🟢 Alto: Operación normal  
  - 🟡 Medio: Revisión recomendada  
  - 🔴 Bajo: Intervención inmediata  

- **Acción sugerida por el agente**
  - Mantener  
  - Revisar  
  - Intervenir
